# 🎓 ACADEX — Smart Student Management System

> A comprehensive, full-stack student management platform designed to streamline academic life for students, faculty, and administrators.

---

## 📌 Overview

**ACADEX** is an all-in-one academic platform that brings together course management, mentorship, smart notes, career guidance, and more — all under one roof.

---

## ✨ Features

| Module | Description |
|---|---|
| 📚 **Courses & Attendance** | Track course enrollment and attendance in real time |
| 📝 **Assignments & Submissions** | Submit and manage assignments with file uploads |
| 🧠 **Smart Notes** | AI-assisted note-taking and organization |
| 📅 **Study Planner** | Personal study schedule and task management |
| 🏫 **Faculty Doubt Desk** | Direct Q&A between students and faculty |
| 🤝 **Senior-Junior Mentorship** | Peer mentorship with approval workflows |
| 💬 **Student Community** | Course-based discussion rooms |
| 🆘 **Student Help Center** | Support ticketing and resolution |
| 🧭 **Student Counselling** | Academic and personal counselling portal |
| ⚠️ **Early Warning System** | Detect at-risk students and trigger interventions |
| 💡 **Project & Idea Hub** | Collaborate on student-led projects and ideas |
| 🚀 **Career Guidance** | Career resources, job listings, and guidance |
| 🔔 **Notifications** | Live dashboard alerts and notifications |
| 🗂️ **File Preview** | In-browser preview for PDFs, images, and text files |
| 👨‍💼 **Admin Tools** | OCR, Redis caching, role management, department staff |

---

## 🛠️ Tech Stack

### Backend
- **Django** (Python) — REST API
- **Redis** — Caching and real-time features
- **OCR** — Document text extraction

### Frontend
- **Next.js** (React) — Web application
- **Express.js** — Community & API services

---

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+
- Redis server
- PostgreSQL (or SQLite for development)

### Backend Setup
```bash
cd acadex-backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend Setup
```bash
cd acadex-frontend
npm install
npm run dev
```

### Community Backend
```bash
cd acadex
npm install
npm start
```
